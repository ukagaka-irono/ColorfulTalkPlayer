# ColorfulTalkPlayer 仕様書

> シリーズ全体の仕様書: [ColorfulTalk](https://github.com/ukagaka-irono/ColorfulTalk)（`docs/spec/player.md` と同じ内容）

ColorfulTalk の音声合成エンジンを使った公式アプリです。文章を読み上げたり、WAV ファイルに書き出したりできます。

## 種類

| 種類 | 作り方 | 特長 |
|---|---|---|
| ColorfulTalkPlayer Web | 全エンジンと ColorfulYomi を 1 つの WebAssembly（約 140KB）にして、ブラウザだけで動かす | インストール不要。音声はブラウザの中で作り、外部に送らない |
| Windows / Mac 版 | Web 版と同じ画面を Tauri 2 で包む。エンジンと辞書を実行ファイルに組み込む | 保存先を選んで WAV を保存、コマンドラインからの読み上げ・WAV 出力 |

版は 1.0.0。中のエンジンは V3 3.0.0、V2 2.0.0、V1 1.0.0、nano 1.0.0、ColorfulYomi 1.0.0（`engines/` のサブモジュール）。

## 機能

| 機能 | Web | Windows / Mac |
|---|---|---|
| 漢字かな交じり文の読み上げ（ColorfulYomi） | ✓ | ✓ |
| 記号列を直接入力して読み上げ | ✓ | ✓ |
| 変換した記号列の表示・修正・読み上げ | ✓ | ✓ |
| エンジンと声の選択（V3 の 3 種、V2 の 14 種、V1 の 10 種、nano の 4 種） | ✓ | ✓ |
| スライダー: 話速・音量（全エンジン）、声の高さ・抑揚・声道の長さ・張り・息っぽさ・ゆらぎ（V3） | ✓ | ✓ |
| V3 のサンプリング周波数（8〜48kHz） | ✓ | ✓ |
| 設定のプリセット保存と切り替え | ✓（ブラウザに保存） | ✓（アプリに保存） |
| WAV に書き出し | ✓（ダウンロード） | ✓（保存先を選ぶ） |
| WAV の周波数を 44.1kHz / 48kHz に変換 | ✓ | ✓ |
| ユーザー辞書（読みとアクセントの登録・試し再生・削除） | ✓（ブラウザに保存） | ✓（アプリに保存） |
| 長い文章を文ごとに区切って間を入れる | ✓ | ✓ |
| コマンドラインから読み上げ・WAV 出力（画面を出さない） | ― | ✓ |

- V1・V2・nano は API が話速だけなので、声の高さなどのスライダーは使えません（灰色になります）。音量は全エンジンでアプリ側で掛けます
- 記号列に誤りがあると、原因の位置に ▶◀ を付けて知らせます
- 辞書（26MB）は Web 版では `dic/colorful_talk.dic` から読み込みます。置いていないときは、利用者が手元の辞書ファイルを選べます。
  辞書がなくても記号列の入力は使えます
- 文の区切り: 句点・？・！の後は 0.3 秒、行末は 0.45 秒、空行（段落）は 0.7 秒の間を入れます

## 文の区切りと記号列の長さ

ColorfulYomi は文ごとに記号列にし、エンジンにも文ごとに渡します。V3 は 1 回 512 モーラ、V1・V2 は 256 モーラ、nano は 254 モーラまでです。
1 文がこれを超えると「記号列が長すぎます」と表示します（読点で文を分けてください）。

## コマンドライン（Windows / Mac 版）

```bash
ColorfulTalkPlayer -t "今日はいい天気です。" -o out.wav -v v3:f1 -s 1.2
```

| オプション | 意味 |
|---|---|
| `-t TEXT` / `-f FILE` | 読み上げる文章（`-f` は UTF-8 のテキストファイル） |
| `-k` | 文章を記号列として扱う（ColorfulYomi を通さない） |
| `-o FILE` | WAV の出力先。省略すると再生 |
| `-v ENGINE:VOICE` | エンジンと声（例 `v3:m1`, `v2:f3`, `v1:k1`, `nano:r`）。`--voices` で一覧 |
| `-s` / `-g` | 話速・音量（1 = 標準） |
| `-p HZ` / `-a X` | 声の高さ・抑揚（V3） |
| `-r HZ` | 出力のサンプリング周波数（V3 は合成時に、ほかは変換） |
| `-u CSV` | ユーザー辞書（`表層形,読み,アクセント,品詞`、ColorfulYomi と同じ形式） |
| `--voices` / `--version` / `-h` | 声の一覧・版・使い方 |

最初の引数が `-` で始まるとコマンドラインとして動き、画面は出しません。
Windows では画面のアプリとして作っているため、コマンドプロンプトは終わりを待たずに次の入力に戻ります。
終わりを待つときは `start /wait ColorfulTalkPlayer ...`（cmd）、`Start-Process -Wait`（PowerShell）を使ってください。

## 構成

| 場所 | 内容 |
|---|---|
| `engines/` | 各エンジンと ColorfulYomi（git サブモジュール） |
| `core/pl_core.c` | 全エンジンと ColorfulYomi をまとめた C の窓口。Web 版とデスクトップ版で共通 |
| `web/` | 画面（HTML・CSS・JavaScript、ビルドの道具なし）。`web/engine/` は WebAssembly（ビルド済みを同梱） |
| `src-tauri/` | デスクトップ版（Rust）。`core/` と `engines/` の C を cc でビルドして組み込む |
| `scripts/` | WebAssembly のビルド、辞書の取得 |
| `tests/` | WebAssembly の出力をエンジンの `ctalk` と比べる試験 |

V1・V2・V3 は共通部分（記号列の解析・WAV・V1/V2 の固定小数点コア）のソースが同じなので、1 つにまとめてリンクしています。
V1 は 10 種の声をすべて組み込んだビルド（`CT1_VOICE_ALL`）を使います。

## 確認したこと

| 項目 | 結果 |
|---|---|
| WebAssembly の出力とエンジンの `ctalk`（Windows・MSVC）の比較 | V2・V1・nano はビット単位で一致。V3 は浮動小数点の数学関数の違いで ±4 以内（長さは一致） |
| ColorfulYomi の変換 | `cyomi` と同じ記号列 |
| Web 版の画面（Chromium 系） | 4 エンジンの読み上げ、記号列の誤りの表示、ユーザー辞書、プリセット、WAV（48kHz 変換）の保存、幅 375px の表示 |
| Windows 版（Windows 11、WebView2） | 組み込んだ辞書の読み込み、画面からの読み上げ、コマンドラインの WAV 出力（V3・V2 の 44.1kHz 変換・nano・ユーザー辞書・記号列の誤り） |

未確認: Mac 版のビルドと動作（Mac がないため）、デスクトップ版の「WAV で保存」の保存ダイアログ（自動では操作できないため）、
インストーラー（`npx tauri build` の NSIS / dmg）の作成。
